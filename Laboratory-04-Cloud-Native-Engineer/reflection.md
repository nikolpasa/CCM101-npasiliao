# Reflection

In this laboratory activity, I learned more about cloud-native technologies, especially Docker and containers. I learned how containers can be used to run applications in an isolated environment without needing to install everything directly on the host system.

I also learned how to use basic Docker commands to check containers, images, and running services. At first, I found some of the commands confusing, but after practicing them in the KillerCoda environment, I became more comfortable using the terminal.

One thing I learned from this activity is that containers can make application deployment easier and more consistent. I also learned the importance of organizing files and screenshots properly in my GitHub repository so that my work can be documented clearly.

Overall, this laboratory helped me understand how cloud-native tools such as Docker are used in modern application development and deployment. It also improved my confidence in using Linux commands, Docker, and Git for cloud computing tasks.
