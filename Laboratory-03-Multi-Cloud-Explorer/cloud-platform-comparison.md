## 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services among the three major providers. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other IT requirements. This makes AWS suitable for organizations with different types of workloads.

## 2. Which cloud provider is best for organizations heavily using Microsoft technologies?

Microsoft Azure is the best choice for organizations that already depend heavily on Microsoft technologies. Azure integrates closely with technologies such as Windows Server, Microsoft SQL Server, Microsoft 365, and Microsoft Entra ID. This integration can make cloud migration and hybrid cloud management easier for Microsoft-based organizations.

## 3. Which cloud provider is strongest in AI and Kubernetes?

Google Cloud is a strong choice for organizations focused on artificial intelligence, machine learning, and Kubernetes. Google has extensive experience in AI and provides services and infrastructure for machine learning and data analytics. Google Kubernetes Engine (GKE) is also a major managed Kubernetes service designed for deploying and managing containerized applications.

## 4. Which cloud provider would you personally choose and why?

I would personally choose AWS because it provides a wide range of cloud services that can support different types of projects and organizations. It offers services for computing, storage, databases, networking, security, and many other requirements. As an IT student, learning AWS can also help me understand different areas of cloud computing and prepare for future cloud-related work.

## Service Equivalence Table

The following table shows equivalent services across AWS, Microsoft Azure, and Google Cloud Platform.

| Cloud Service Category  | AWS                                     | Microsoft Azure                | Google Cloud                   |
| ----------------------- | --------------------------------------- | ------------------------------ | ------------------------------ |
| **Virtual Machine**     | Amazon EC2                              | Azure Virtual Machines         | Google Compute Engine          |
| **Object Storage**      | Amazon S3                               | Azure Blob Storage             | Google Cloud Storage           |
| **Identity Management** | AWS IAM                                 | Microsoft Entra ID             | Google Cloud IAM               |
| **SQL Database**        | Amazon RDS                              | Azure SQL Database             | Cloud SQL                      |
| **Kubernetes**          | Amazon Elastic Kubernetes Service (EKS) | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

### Service Equivalence Explanation

Although the cloud providers use different names for their services, many of them provide similar functions. For example, Amazon EC2, Azure Virtual Machines, and Google Compute Engine all provide virtual machines for running applications and workloads. Similarly, Amazon S3, Azure Blob Storage, and Google Cloud Storage provide object storage, while EKS, AKS, and GKE provide managed Kubernetes services.

Understanding these equivalent services makes it easier to compare cloud providers and select the platform that best matches an organization's requirements.
