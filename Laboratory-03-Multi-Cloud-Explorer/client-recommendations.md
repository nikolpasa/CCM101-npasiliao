# Client Recommendations

## Scenario A – Startup Company

### Recommendation: Amazon Web Services (AWS)

I recommend AWS for the startup company because it provides a wide range of services that can support a growing business. AWS allows the startup to begin with the resources it needs and scale them as the company grows. Its large selection of services also gives the startup flexibility to add new technologies in the future.

### Recommended Services

1. **Amazon EC2** – Provides virtual servers for hosting the startup's website and applications.
2. **Amazon S3** – Stores files, images, backups, and other application data.
3. **Amazon RDS** – Provides a managed relational database for business applications.
4. **Amazon VPC** – Provides a secure virtual network for AWS resources.

---

## Scenario B – University Using Microsoft Technologies

### Recommendation: Microsoft Azure

I recommend Microsoft Azure for the university because it provides strong integration with Microsoft technologies. If the university already uses Windows Server, Microsoft SQL Server, Microsoft 365, and Microsoft Entra ID, Azure can provide a familiar environment for managing cloud resources. Azure can also support hybrid environments where some university systems remain on-premises while other services operate in the cloud.

### Recommended Services

1. **Azure Virtual Machines** – Allows the university to run Windows and Linux virtual machines.
2. **Azure SQL Database** – Provides a managed relational database for university applications.
3. **Microsoft Entra ID** – Provides identity and access management for users and applications.
4. **Azure Virtual Network** – Provides private networking for university cloud resources.

---

## Scenario C – AI Research Laboratory

### Recommendation: Google Cloud Platform (GCP)

I recommend Google Cloud for the AI research laboratory because it provides strong services for artificial intelligence, machine learning, and data analytics. Google Cloud also provides infrastructure and tools that can support researchers working with large datasets and machine learning workloads. Its Kubernetes services can also help researchers deploy containerized applications and experiments.

### Recommended Services

1. **Google Compute Engine** – Provides virtual machines for research workloads and applications.
2. **Google Cloud Storage** – Stores large datasets, research files, and machine learning data.
3. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized AI and research applications.
4. **BigQuery** – Provides a data warehouse service for analyzing large datasets.

---

## Scenario D – Global E-Commerce Company

### Recommendation: Amazon Web Services (AWS)

I recommend AWS for the global e-commerce company because it provides services that can support highly scalable and globally distributed applications. The company can deploy applications in different geographic locations and use managed services for databases, storage, networking, and computing. AWS also provides many services that can help the company handle increasing customer traffic and large amounts of product and transaction data.

### Recommended Services

1. **Amazon EC2** – Runs the company's e-commerce website and backend applications.
2. **Amazon S3** – Stores product images, website files, backups, and other objects.
3. **Amazon RDS** – Manages relational databases containing product, customer, and transaction information.
4. **Amazon VPC** – Provides a controlled network environment for the company's cloud infrastructure.
5. **Amazon CloudFront** – Delivers website content to customers from locations closer to them.
