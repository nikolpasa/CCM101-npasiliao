Amazon Web Services (AWS) Research
1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use for computing, storage, databases, networking, security, analytics, and other IT needs.

AWS allows businesses to use cloud resources without having to purchase and maintain all of the physical hardware themselves. Organizations can select the services and resources they need and scale them according to their requirements.

2. Global Infrastructure

AWS has a global infrastructure organized into Regions and Availability Zones. An AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region.

Availability Zones are connected using low-latency and high-bandwidth networking. Using multiple Availability Zones can help organizations design applications that remain available even if one location experiences a failure.

AWS also provides other infrastructure options, including Local Zones and Wavelength Zones, which can place certain resources closer to users or specific network locations.

3. Cloud Management Console

The AWS Management Console is a web-based application used to access and manage AWS services. It provides centralized access to individual AWS service consoles.

Users can search for services, manage resources, view notifications, access AWS CloudShell, and manage account and billing information through the console.

4. Four Core Services

Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads in the AWS cloud.

Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data. It can be used for files, backups, websites, mobile applications, archives, and other types of data.

Amazon RDS

Amazon Relational Database Service (RDS) is a managed relational database service. It simplifies tasks such as database setup, backups, patching, and scaling.

Amazon VPC

Amazon Virtual Private Cloud (VPC) allows organizations to create and control virtual networking environments for their AWS resources. It can be used to organize networks, subnets, routing, and security controls.

5. Three Advantages
1. Scalability

AWS allows organizations to increase or decrease cloud resources according to their workload requirements.

2. Global Availability

AWS provides infrastructure in different geographic locations around the world, allowing organizations to deploy resources closer to their users.

3. Wide Range of Services

AWS provides a large collection of services for computing, storage, databases, networking, security, analytics, artificial intelligence, and other cloud requirements.

6. Typical Enterprise Use Cases

AWS is commonly used by enterprises for:

Hosting websites and web applications
Running business applications on virtual servers
Storing and backing up company data
Managing relational databases
Building highly available applications
Data analytics and artificial intelligence
Disaster recovery and cloud migration
