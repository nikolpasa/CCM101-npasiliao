Microsoft Azure Research
1. Brief Overview

Microsoft Azure is a cloud computing platform provided by Microsoft. It provides cloud services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

Azure allows organizations to build, deploy, manage, and scale applications and IT infrastructure using Microsoft's cloud infrastructure.

2. Global Infrastructure

Azure has a global infrastructure made up of geographic Regions and Availability Zones. An Azure region is a geographic area containing cloud infrastructure, while Availability Zones are separate groups of datacenters within a region.

Availability Zones have independent power, cooling, and networking infrastructure. They help organizations improve application availability and protect workloads from failures affecting a particular datacenter or zone.

Azure also has region pairs for some regions, which can support certain disaster recovery and geo-redundancy strategies.

3. Cloud Management Console

The Azure portal is a web-based, unified console for managing Azure resources and subscriptions.

Users can create, manage, and monitor cloud resources through the portal. The portal also provides dashboards and tools that help users organize and manage their Azure environment.

4. Four Core Services

Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources that allow organizations to run applications and operating systems in the Azure cloud.

Azure Blob Storage

Azure Blob Storage is designed to store large amounts of unstructured data such as documents, images, videos, backups, and logs.

Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL technologies. It allows organizations to run databases without managing all of the underlying infrastructure themselves.

Azure Virtual Network

Azure Virtual Network provides networking capabilities for Azure resources. It allows organizations to create private network environments and control communication between cloud resources.

5. Three Advantages

1. Microsoft Integration

Azure works closely with Microsoft technologies and services, making it suitable for organizations already using products such as Windows Server, Microsoft 365, and Microsoft Entra ID.

2. Scalability

Azure allows organizations to increase or decrease resources based on their application and business requirements.

3. Global Infrastructure

Azure provides regions and availability zones in many geographic locations, allowing organizations to deploy applications closer to their users and design highly available solutions.

6. Typical Enterprise Use Cases

Azure is commonly used by enterprises for:

Hosting business applications
Migrating Windows Server workloads
Running Microsoft SQL databases
Cloud storage and backup
Hybrid cloud environments
Enterprise networking
Artificial intelligence and machine learning
Disaster recovery
Application development and deployment
