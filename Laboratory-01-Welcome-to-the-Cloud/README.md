# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic tools and skills needed by a cloud infrastructure engineer. The activity focuses on using a Linux environment, gathering system information, organizing files, and creating a professional GitHub portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Create and organize files and directories.
- Create and maintain a GitHub repository.
- Document technical activities using Markdown.

## Activities Performed

1. Accessed the Ubuntu Linux environment using KillerCoda.
2. Created a new Linux user with a home directory and Bash shell.
3. Added the user to the sudo group.
4. Logged into the new user account.
5. Gathered Linux distribution, kernel, CPU, memory, and disk information.
6. Created the required directory and file structure.
7. Created Markdown documentation.
8. Created a GitHub Cloud Computing portfolio.
9. Organized laboratory files and screenshots.
