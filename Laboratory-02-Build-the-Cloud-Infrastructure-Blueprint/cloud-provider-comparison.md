# Cloud Provider Comparison

## Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management | AWS IAM | Microsoft Entra ID | Google Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?
AWS is generally considered to offer the broadest range of services, with hundreds of products spanning compute, storage, databases, analytics, IoT, and more. As the first major cloud provider, it has had the longest time to build out a deep and varied service catalog, and it remains the market leader in terms of overall service breadth and global infrastructure footprint.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure would be the natural recommendation for a Microsoft-centric organization. It integrates tightly with tools like Active Directory (now Entra ID), Windows Server, Office 365, and .NET, which means existing licenses, identity systems, and admin skill sets carry over smoothly instead of requiring a separate ecosystem to manage.

### 3. Which platform is widely recognized for AI, Machine Learning, and Kubernetes services?
Google Cloud Platform is widely recognized in this space, largely because Google originally created Kubernetes and continues to lead its development, and because its AI/ML tooling (like Vertex AI and the underlying TPU hardware) builds directly on Google's own research and infrastructure. GCP is often the platform of choice for teams doing heavy machine learning or container-orchestration work.

### 4. What similarities did you observe among the three cloud providers?
All three providers offer the same core categories of infrastructure — compute, storage, networking, and identity and access management — just under different product names. Each also follows a pay-as-you-go pricing model, provides global data center regions, and emphasizes scalability, security, and automation as core selling points of their platforms.
