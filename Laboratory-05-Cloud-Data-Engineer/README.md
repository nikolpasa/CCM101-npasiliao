# Laboratory 5: The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I explored cloud storage technologies and deployed an S3-compatible object storage server using Docker in the KillerCoda Ubuntu environment. The activity focused on understanding object storage and preparing a storage environment for a photo-sharing application.

## Objectives

- Differentiate between Block Storage, File Storage, and Object Storage.
- Deploy a MinIO-compatible object storage server using Docker.
- Understand Docker port mapping and environment variables.
- Access a cloud storage service through a web console.
- Learn how buckets organize objects in cloud storage.
- Document deployment procedures and troubleshooting results using Markdown.
- Maintain a structured GitHub Cloud Computing portfolio.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO-compatible storage image
- Git and GitHub
- Markdown
- Web browser
- Linux command-line utilities

## Skills Learned

- Creating and organizing project directories in Linux.
- Running and inspecting Docker containers.
- Mapping container ports to host ports.
- Configuring container environment variables.
- Comparing cloud storage architectures.
- Writing technical documentation in Markdown.
- Troubleshooting container deployment and web-console access.
