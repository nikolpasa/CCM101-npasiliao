# Automation Research

## 1. Bash Script
A Bash script is a text file containing Linux commands that can be executed automatically instead of typing them individually. The `#!/bin/bash` line, called the shebang, tells the system to use the Bash interpreter to run the script.

## 2. Variables
Variables store values such as directory paths, filenames, or dates that can be reused throughout a script. Using variables like `$BACKUP_DIR` makes scripts easier to update and reduces mistakes caused by repeatedly typing the same information.

## 3. Cron Job
A cron job is a scheduled task that Linux runs automatically at specified times or intervals. It is useful in cloud operations because it can perform routine tasks such as backups, system maintenance, and log cleanup without requiring manual execution.
