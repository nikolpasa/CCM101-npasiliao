# Mission 9 Reflection: Cloud Automation Engineer

Throughout this laboratory activity, I learned how automation helps cloud engineers manage repetitive tasks more efficiently. When handling hundreds of cloud servers, manually executing commands takes considerable time and increases the possibility of human error. By using Bash scripts and Cron jobs, administrators can schedule important operations such as backups without constantly monitoring or executing them manually.

However, I also realized that automation comes with risks. A small mistake in a script can cause serious problems, especially when the same script runs across thousands of servers. For example, an incorrect command could accidentally delete important files or interrupt services. This taught me that scripts should always be reviewed, tested, and monitored before being deployed on a large scale.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripts contain commands that perform actions, such as creating directories and compressing files. In contrast, Docker Compose YAML files describe how containers and their services should be configured and managed. Both tools simplify cloud operations, but they serve different purposes.

Looking back at Laboratories 1 through 9, my understanding of cloud computing has improved significantly. At first, I mainly understood cloud computing as accessing computing resources through the internet. Through the laboratory activities, I gained practical experience with Linux commands, cloud platforms, Docker containers, object storage, deployment, monitoring, security, and automation. These experiences helped me understand how different technologies work together to support cloud infrastructure.

Among the cloud engineering roles, I enjoyed the Cloud Automation Engineer role the most because I like finding ways to make repetitive tasks easier and more efficient. Creating a backup script showed me how a few commands can save time and improve consistency. This mission encouraged me to continue developing my scripting and automation skills.
