# Security Audit Report

## 1. Principle of Least Privilege (PoLP)
The Principle of Least Privilege means giving users only the permissions they need to perform their tasks. This is important in cloud computing because it reduces the risk of unauthorized access and limits the damage if an account is compromised.

## 2. Attack Surface
An attack surface refers to all the possible entry points that attackers could use to access a virtual machine, such as open ports, running services, and vulnerable applications. Reducing unnecessary services and closing unused ports makes the server more secure.

## 3. Default Deny Policy
A Default Deny Policy blocks incoming network traffic unless it is specifically allowed by a firewall rule. It is safer because unknown or unwanted connections are blocked automatically instead of relying on identifying every possible attacker.
